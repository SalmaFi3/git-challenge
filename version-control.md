# Comprendre le Version Control

## Qu'est-ce que le Version Control ?

Le version control (ou contrôle de version) est un système qui enregistre
l'historique des modifications apportées à un fichier ou un ensemble de fichiers
au fil du temps. Il permet de revenir à une version précédente à tout moment.

## Pourquoi en a-t-on besoin ?

- **Historique complet** : on peut voir qui a modifié quoi et quand
- **Collaboration** : plusieurs développeurs peuvent travailler sur le même
  projet sans écraser le travail des autres
- **Sécurité** : si une erreur est introduite, on peut revenir à une version
  stable précédente
- **Branches** : on peut expérimenter de nouvelles fonctionnalités sans
  affecter le code principal
- **Traçabilité** : chaque modification est documentée avec un message de commit

## Exemple concret

Sans version control, si deux développeurs modifient le même fichier,
l'un écrase le travail de l'autre. Avec Git, les modifications sont fusionnées
intelligemment et les conflits sont détectés.

## Outils populaires

- **Git** (le plus utilisé, décentralisé)
- SVN (centralisé)
- Mercurial
