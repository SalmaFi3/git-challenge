## 🧠 Ce que j'ai appris

### 📌 Section Introduction
- Le **version control** permet de suivre l'historique des modifications et de collaborer sans conflits
- Git est un système décentralisé : chaque développeur a une copie complète du repo

### 📌 Section Fundamentals
- Configurer son identité Git (`user.name`, `user.email`) est indispensable avant tout commit
- La **zone de staging** permet de choisir précisément quels fichiers entrent dans un commit
- Un bon message de commit suit la convention : `type: description claire`
  - `feat:` nouvelle fonctionnalité
  - `fix:` correction de bug
  - `docs:` documentation
  - `chore:` tâches de maintenance
